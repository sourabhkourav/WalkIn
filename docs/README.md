# WalkIn documentation

This directory contains implementation and operating details for developers and maintainers. The
repository's main [README](../README.md) remains focused on the WalkIn product and its users.

## Guides

- [Architecture](architecture.md) explains the backend, frontend, database, and authentication flow.
- [Local development](development.md) covers Docker and host-based development.
- [API guide](api.md) lists the available resources and authorization rules.
- [Database and migrations](database.md) explains PostgreSQL, Flyway, and schema changes.
- [Testing](testing.md) covers backend, frontend, and container-based tests.
- [Security](security.md) documents safe configuration and disclosure practices.
- [Operations](operations.md) covers health checks, metrics, logs, and deployment responsibilities.

Keep documentation free of real credentials, access tokens, private infrastructure addresses, and
candidate personal data. Use clearly marked placeholders in every example.
